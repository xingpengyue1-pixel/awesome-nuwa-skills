## 效果示例

### 1. 清除模糊语言

> 用户: 帮我把这段公文改得更清晰——"关于进一步加强和改进新形势下相关工作的若干意见的通知"
>
> Claude: 奥威尔会说：这句话什么也没有说。它用十九个字躲避了一个简单的问题——你要做什么？改成：关于 X 问题的处理办法。如果你自己都说不清"相关工作"是什么，读者更不可能知道。每一个模糊的词都是一面小小的烟幕弹。

### 2. 六条规则审查

> 用户: 用奥威尔的六条写作规则帮我审查这篇文章。
>
> Claude: 规则一——永远不要使用在印刷品中经常见到的隐喻或比喻：你的第二段用了"在新时代的浪潮中乘风破浪"，这个比喻已经死了，删掉它。规则二——能用短词的不要用长词：第四行"utilize"改成"use"。规则五——能用日常英语就不要用外来词：没有必要用"paradigm"，说"模式"。规则六——宁可打破以上任何一条规则，也不要说出任何野蛮的话。

### 3. 政治语言解码

> 用户: 用奥威尔的视角分析这段政治声明背后真正在说什么。
>
> Claude: 奥威尔在《政治与英语》中说：政治语言的设计就是为了让谎言听起来像真话、让谋杀变得体面、让空气变得坚固。这段声明说"优化资源配置"，意思是裁员。说"战略性调整"，意思是失败后换方向。说"充分考虑各方关切"，意思是什么都不做。把每个短语翻译回人话，你就能看到真正的意思。

### 4. 真相写作

> 用户: 我想写一篇关于社会问题的文章，但不知道怎么开头。
>
> Claude: 奥威尔说，写作的第一动机应该是政治目的——想要把世界推向某个方向，想要改变别人对理想社会的看法。不要从修辞开始，从事实开始。你看到了什么不公正的事？用最简单的语言把它写下来。不要修饰，不要躲在被动语态后面。谁做了什么，对谁做了什么，造成了什么后果。这就是开头。

## 蒸馏了什么

本技能从奥威尔的写作理论和创作实践中提取了以下核心要素：

- **六条写作规则** — 来自《政治与英语》的六条黄金准则，是一切清晰写作的基础
- **反对模糊语言** — 模糊的语言是不诚实思维的工具，清晰的语言是思考的前提
- **政治语言解码** — 识别和翻译政治话语中的委婉语、被动语态和抽象名词
- **为真相写作** — 写作不是装饰，是把你看到的真实世界传达给读者
- **简单即力量** — 用最普通的词、最短的句子、最直接的结构
- **窗玻璃式散文** — 好的散文像一块透明的玻璃，读者透过它直接看到事物本身

核心参考作品：《1984》《动物农场》《政治与英语》《我为什么写作》《向加泰罗尼亚致敬》

## 调研来源

- 《政治与英语》(1946) — 奥威尔写作理论的核心文本
- 《我为什么写作》(1946) — 奥威尔对写作动机的自我剖析
- 《1984》附录"新话的原则" — 语言如何塑造思想
- Bernard Crick《奥威尔传》中对其写作习惯的记录
- 奥威尔给出版商和编辑的书信集
