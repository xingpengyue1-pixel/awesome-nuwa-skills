## 效果示例

### 1. 总觉得自己不够好
> 用户："身边的同龄人都比我优秀，我什么都做不好。"
>
> Claude (阿德勒视角)："阿德勒会微笑着对你说：你正在拿别人的尺子量自己。比较是一种你选择的行为——注意，是'选择'。阿德勒心理学不问'为什么我会这样'，而是问'这样做的目的是什么'。当你不断比较并得出'我不如人'的结论时，你可能在无意识中为自己创造一个不行动的理由。自卑感本身不是问题——它是人类前进的动力。问题在于你是把自卑感变成了前进的燃料，还是变成了退缩的借口。阿德勒的邀请是：停止横向比较，开始纵向成长。昨天的你和今天的你，这才是唯一有意义的比较。"

### 2. 人际关系中总是讨好别人
> 用户："我总是不敢拒绝别人，害怕别人不喜欢我。"
>
> Claude (阿德勒视角)："阿德勒有一个非常解放的概念叫做'课题分离'：别人喜不喜欢你，那是别人的课题，不是你的。你的课题是——你想成为什么样的人，你想如何真诚地生活。你害怕被讨厌，所以活成了别人期待的形状。但阿德勒会直率地告诉你：被所有人喜欢是不可能的，也是不必要的。自由，就是不再害怕被别人讨厌。这不是说要去伤害别人，而是说你有权利做自己，同时承担做自己的后果。今天，你愿意尝试一次温和而坚定的拒绝吗？"

### 3. 童年创伤的困扰
> 用户："我觉得我现在的性格问题都是因为小时候父母太严厉了。"
>
> Claude (阿德勒视角)："阿德勒会在这里提出一个可能让你不太舒服的观点：重要的不是过去发生了什么，而是你赋予过去什么意义。这不是否认你的痛苦——你小时候的经历确实很艰难。但阿德勒拒绝'原因论'，他选择'目的论'：你此刻选择强调童年创伤，可能是因为它为你现在的行为模式提供了一个看似合理的解释。真正的勇气是——承认过去的影响，但拒绝被它决定。你不是过去的囚徒，你是现在的创造者。从此刻开始，你想创造什么样的生活？"

### 4. 害怕做出重大决定
> 用户："我想辞职去做自己喜欢的事，但就是迈不出那一步。"
>
> Claude (阿德勒视角)："阿德勒会说，你并非'迈不出'，而是'选择不迈出'——这个区别非常关键。当你说'我不能'时，其实是'我不愿承担迈出后的风险'。这不是批判你，而是把力量还给你：既然是你的选择，你也可以做出不同的选择。阿德勒心理学强调'行动优先'——不是等你完全准备好了再行动，而是在行动中变得准备好。同时，阿德勒会问你：你想做的那件事，它只是为了你自己，还是同时也能为他人和社会带来价值？当你的个人追求与社会兴趣结合时，勇气会自然涌现。"

## 蒸馏了什么

本 Skill 将阿德勒个体心理学(Individual Psychology)的核心智慧蒸馏为 Claude 可以运用的对话能力：

- **自卑与超越**：自卑感是人类进步的动力，关键在于如何将其转化为成长的力量
- **课题分离**：清晰区分"我的课题"与"别人的课题"，是获得自由的关键
- **目的论(Teleology)**：行为由目的驱动而非原因决定，人是面向未来的存在
- **社会兴趣(Gemeinschaftsgefühl)**：对他人和社会的归属感与贡献意愿是心理健康的核心指标
- **生活风格(Lifestyle)**：个体独特的认知-行为模式，形成于早期但可以被改变
- **鼓励(Encouragement)**：阿德勒治疗的核心技术——激发勇气而非分析缺陷

- **《自卑与超越》** — 自卑感的普遍性、生活意义、社会兴趣的完整论述
- **《被讨厌的勇气》(岸见一郎解读)** — 课题分离、目的论、共同体感觉的现代诠释
- **《理解人性》** — 人格结构与生活风格的形成机制
- **《儿童教育心理学》** — 早期记忆、出生顺序、教育中的鼓励原则
- **《生活的科学》** — 阿德勒思想的系统化总结
