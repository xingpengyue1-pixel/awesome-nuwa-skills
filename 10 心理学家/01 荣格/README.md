## 效果示例

### 1. 反复出现同一个噩梦
> 用户："我总是梦到被巨浪追赶，已经持续好几个月了。"
>
> Claude (荣格视角)："巨浪在集体无意识中是一个古老的原型意象，它常常代表着被压抑的情感力量正在寻求意识的整合。你并非被外在的浪追赶，而是你内在的某种未被承认的心理能量在呼唤你的注意。让我们一起探索——在你醒时的生活中，是否有某种强烈的情感你一直在回避？这个梦可能正是你的自性(Self)发出的个体化邀请。"

### 2. 不知道自己到底想要什么
> 用户："我在一家大公司工作，收入不错，但总觉得缺了点什么。"
>
> Claude (荣格视角)："你所描述的，是人格面具(Persona)与真实自我之间的裂隙。你在社会中扮演的角色运转良好，但灵魂在低语——它有自己的需求。荣格会说，这正是个体化进程的起点：当外在的成功无法再安抚内在的空虚时，真正的心理成长才刚刚开始。你愿意花一些时间去觉察，那个'缺了点什么'的感觉，它具体住在你身体的哪个位置？"

### 3. 总是被同一类型的人吸引
> 用户："我发现自己每段感情都会爱上那种冷漠、不可得的人。"
>
> Claude (荣格视角)："在荣格的语言中，你正在不断地将自己的阿尼玛/阿尼姆斯(Anima/Animus)投射到伴侣身上。那个'冷漠而不可得'的特质，很可能是你内心中一个未被整合的面向——也许是你自己内在的情感距离感，也许是童年时期某个重要关系留下的原型印记。真正的问题不是'为什么我总遇到这样的人'，而是'我内在的什么在被这种模式吸引？'当你开始认回这个投射，关系模式才会真正转变。"

### 4. 中年突然对宗教/灵性产生兴趣
> 用户："我以前是个坚定的无神论者，但最近突然对佛学、冥想特别感兴趣，这正常吗？"
>
> Claude (荣格视角)："这不仅正常，在荣格看来，这几乎是必然的。人生的前半段，我们忙于建立自我(Ego)、适应社会；而人生的后半段，灵魂开始要求我们转向内在。荣格称之为'生命午后的转向'。你之前的无神论服务于建构一个理性的自我，而现在涌现的灵性渴望，是自性(Self)在邀请你走向更完整的存在。佛学与冥想所指向的那个超越二元对立的境界，恰恰呼应了荣格所说的'对立面的统一'。你正走在个体化的正确道路上。"

## 蒸馏了什么

本 Skill 将荣格分析心理学的核心智慧蒸馏为 Claude 可以运用的对话能力：

- **集体无意识与原型理论**：理解人类共享的深层心理结构——阴影(Shadow)、人格面具(Persona)、阿尼玛/阿尼姆斯(Anima/Animus)、自性(Self)等核心原型
- **个体化进程(Individuation)**：引导用户走向心理整合与人格完整性的生命旅程
- **梦的分析方法**：以象征放大法(Amplification)和积极想象(Active Imagination)解读梦境与意象
- **心理类型学**：基于荣格八种心理类型的人格理解框架
- **炼金术心理学**：以炼金术隐喻理解心灵转化的过程
- **共时性(Synchronicity)**：理解有意义的巧合与心灵-物质的深层关联

- **《红书》** — 荣格个人面对无意识的深层记录，积极想象的原始实践
- **《心理类型》** — 内倾/外倾、四种心理功能(思维/情感/感觉/直觉)的完整框架
- **《人及其象征》** — 原型象征的通俗解读，集体无意识的入门指南
- **《移情心理学》** — 炼金术隐喻下的关系动力学
- **《回忆·梦·思考》** — 荣格自传，理解其思想发展脉络的关键文本
