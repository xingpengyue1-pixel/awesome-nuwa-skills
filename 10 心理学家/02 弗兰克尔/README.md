## 效果示例

### 1. 遭遇重大人生挫折
> 用户："我创业三年的公司倒闭了，感觉一切都完了。"
>
> Claude (弗兰克尔视角)："我能感受到你此刻的痛苦——三年的心血，这不是一个轻飘飘的损失。弗兰克尔会温和地提醒你：苦难本身不是问题，没有意义的苦难才是。你的公司关闭了，但你在这三年里学到的东西、建立的能力、经历的成长——这些并没有消失。现在的问题不是'为什么是我'，而是'这段经历在邀请我成为什么样的人？'弗兰克尔在集中营里失去了一切，却发现了人最深处的自由：选择如何面对。你现在也站在这个选择的面前。"

### 2. 感到生活毫无意义
> 用户："每天上班下班，周而复始，我不知道活着到底为了什么。"
>
> Claude (弗兰克尔视角)："弗兰克尔会说，你问错了方向——不是你在问生活要给你什么意义，而是生活在问你：你愿意给出什么？意义不是被找到的，而是被创造的。它有三条路径：通过创造性工作给予世界某种东西；通过爱与体验从世界获得某种东西；或者通过你对不可改变的苦难所采取的态度。此刻你感到的空虚本身就是信号——它说明你的灵魂有更大的容量，只是还没有被填满。让我们从小处开始：今天，有没有一个具体的人，你可以为他做一件有意义的事？"

### 3. 亲人离世后的悲伤
> 用户："我妈妈上个月走了，我每天都在哭，不知道怎么继续。"
>
> Claude (弗兰克尔视角)："首先，请允许自己悲伤——悲伤是爱的另一个名字，你哭泣，恰恰因为那份爱是真实而深沉的。弗兰克尔自己也失去了妻子、父母、兄弟。他说过一段话我想分享给你：'悲伤中有意义，因为它是你对所爱之人的最后致敬。'你的妈妈已经不在了，但她给予你的爱、她对你的塑造、她存在过的事实——这些是永恒的。弗兰克尔认为，过去并非虚无，恰恰相反，过去是最安全的存在形式，因为没有任何力量可以从你那里夺走你曾经经历过的一切。"

### 4. 被迫面对无法改变的困境
> 用户："我被确诊了慢性病，医生说无法治愈，只能控制。"
>
> Claude (弗兰克尔视角)："这个消息一定让你感到沉重，我不会假装轻松。但弗兰克尔——他自己经历过人类最极端的苦难——会告诉你：当我们无法改变处境时，我们被召唤去改变自己。这不是要你假装乐观，而是邀请你发现一种更深层的力量。意义疗法的核心信念是：即使在最受限的条件下，人依然可以决定自己在精神上成为什么样的人。你的身体有了限制，但你的精神空间是无限的。很多人正是在面对疾病的过程中，才第一次真正学会了活着。让我们一步一步来——此刻你最需要被看见的感受是什么？"

## 蒸馏了什么

本 Skill 将弗兰克尔意义疗法(Logotherapy)的核心智慧蒸馏为 Claude 可以运用的对话能力：

- **意义意志(Will to Meaning)**：人的核心驱力不是快乐或权力，而是寻找生命的意义
- **态度价值(Attitudinal Values)**：在无法改变的苦难中，通过选择态度来实现意义
- **创造价值(Creative Values)**：通过工作、创造、给予来实现意义
- **体验价值(Experiential Values)**：通过爱、美、真理的体验来实现意义
- **存在之虚空(Existential Vacuum)**：理解现代人空虚感与无意义感的根源
- **悲剧性乐观主义(Tragic Optimism)**：在痛苦、内疚、死亡面前依然说"是"

- **《活出生命的意义》** — 集中营经历与意义疗法的核心阐述，人类终极自由的发现
- **《追寻生命的意义》** — 意义疗法的理论基础与临床应用
- **《无条件的人》** — 人的尊严不取决于条件，而是内在的精神自由
- **《苦难中的人》** — 苦难作为意义来源的深度探讨
- **《意义的呼唤》** — 意义疗法在日常生活中的实践指南
