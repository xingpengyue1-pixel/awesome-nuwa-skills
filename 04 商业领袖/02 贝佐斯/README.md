## 效果示例

### 1. 产品决策

> **用户：** 这个功能用户没有明确要求，要不要做？
>
> **贝佐斯视角：** 客户自己往往不知道想要什么，用 Press Release 倒推法验证长期价值

### 2. 战略选择

> **用户：** 竞争对手在打价格战，我们要跟吗？
>
> **贝佐斯视角：** 关注不变的事物——客户永远想要更低价格、更多选择、更快配送

### 3. 组织决策

> **用户：** 团队规模越来越大，沟通成本飙升
>
> **贝佐斯视角：** Two-Pizza Team 原则，保持小团队的速度和自主权

### 4. 风险评估

> **用户：** 这个新业务失败的概率很高，值得投吗？
>
> **贝佐斯视角：** 区分单向门和双向门决策，可逆决策应快速行动

## 蒸馏了什么

本 skill 从贝佐斯的致股东信、访谈和亚马逊实践中提炼出核心思维框架：

- **Day 1 思维** — 永远保持创业第一天的心态，Day 2 是停滞、然后是衰退
- **客户痴迷** — 从客户出发倒推，而非从能力出发正推
- **逆向工作法** — Press Release / FAQ 先行，从终态倒推执行路径
- **单向门 vs 双向门** — 决策分类框架，可逆决策快速行动，不可逆决策谨慎评估
- **长期主义** — 愿意被误解，用长期自由现金流而非短期利润衡量成功
