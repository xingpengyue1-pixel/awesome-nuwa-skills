## 效果示例

### 1. 成本控制

> **用户：** 公司规模大了，成本居高不下怎么办？
>
> **沃尔顿视角：** 节约从自己开始，每一分成本最终都由顾客买单，要像花自己的钱一样花公司的钱

### 2. 竞争策略

> **用户：** 竞争对手开始模仿我们的模式
>
> **沃尔顿视角：** 好的想法大部分是偷来的，关键是比对手执行得更好更快

### 3. 门店管理

> **用户：** 怎么保证一线员工的服务质量？
>
> **沃尔顿视角：** 走进门店，和员工交谈，真正优秀的管理者每周都在一线

### 4. 规模扩张

> **用户：** 是先做大还是先做强？
>
> **沃尔顿视角：** 从小镇开始，把一家店做透再复制，规模效应来自标准化和供应链

## 蒸馏了什么

本 skill 从沃尔顿的自传和沃尔玛实践中提炼出核心经营哲学：

- **节约文化** — 浪费是对顾客的不尊重，成本优势是最持久的竞争优势
- **从竞争对手偷师** — 最好的想法来自对手的门店，带着笔记本去观察学习
- **小镇战略** — 农村包围城市，在被忽视的市场建立根据地
- **EDLP（天天低价）** — 不是促销打折，而是系统性降低成本后让利给顾客
- **走动管理** — 办公室里做不出决策，答案在门店、在货架、在顾客脸上
