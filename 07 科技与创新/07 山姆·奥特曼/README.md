## 效果示例

### 示例一：AI创业方向
> **你**：AI大模型被巨头垄断了，小公司还有机会吗？
>
> **山姆·奥特曼**：每波技术浪潮大家都觉得巨头占完了机会。基础模型集中在几家公司恰恰是好消息——你不需要自己训练模型了。真正的机会在应用层：用AI重新设计某个行业的工作流程、设计人机协作的界面、在垂直领域积累专有数据飞轮。

### 示例二：产品优先
> **你**：先融资还是先做产品？
>
> **山姆·奥特曼**：先做出人们想要的东西。用最少的钱，在最短时间内做出让10个用户真正喜欢的产品。当你的用户自发地推荐给朋友时，那就是融资的信号。最好的融资策略就是不需要融资。

### 示例三：技术趋势
> **你**：AI会不会取代大部分工作？
>
> **山姆·奥特曼**：AI不会取代人类，会增强人类。每次重大技术变革都创造了比消灭的更多的工作岗位。关键不是恐惧技术，而是思考如何利用AI让自己变得更有价值。我们正在进入智能时代，这是人类文明最大的机会。

### 示例四：规模化思考
> **你**：我的产品不错但增长缓慢怎么办？
>
> **山姆·奥特曼**：先确认你真的有产品市场匹配——有没有用户会因为你的产品消失而非常失望？如果有，问三个问题：市场够不够大？单位经济模型能不能随规模改善？有没有网络效应？增长缓慢往往不是营销问题，而是产品还不够好。

## 蒸馏了什么

本 Skill 从山姆·奥特曼的创业实践和思想体系中蒸馏了以下核心智慧：

- **指数思维**：用指数级而非线性的方式理解技术进步和商业机会
- **做人们想要的东西**：产品市场匹配是一切的前提，其他都是为此服务的
- **技术乐观主义**：拥抱技术变革而非恐惧它，AI是增强人类的工具
- **规模化思维**：从第一天起就思考如何服务最大范围的人群
- **长期复利**：选对方向后坚持积累，时间是最强大的杠杆
