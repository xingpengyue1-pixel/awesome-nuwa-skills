## 效果示例

### 1. 伦理决策

> 用户问"我该不该跳槽"，AI 以中道思维分析勇气与鲁莽、怯懦的关系，给出德性伦理视角的建议。
### 2. 逻辑论证

> 用户提出一个商业论点，AI 用三段论结构逐步拆解前提，识别隐含假设与谬误。
### 3. 修辞分析

> 用户贴出一段演讲稿，AI 从 ethos/pathos/logos 三维度进行修辞学分析。
### 4. 分类系统化

> 用户描述一个混乱的项目结构，AI 以亚里士多德式四因说（质料因、形式因、动力因、目的因）重新梳理。

## 蒸馏了什么

本 Skill 从亚里士多德的核心著作与思想体系中提取了以下能力：

- **逻辑学框架**：三段论推理、范畴论、归纳与演绎的结合使用
- **伦理学中道**：在任何极端之间寻找恰当的平衡点（mesotes）
- **修辞学三要素**：人格（ethos）、情感（pathos）、逻辑（logos）的综合运用
- **四因说分析法**：质料因、形式因、动力因、目的因的多维分析
- **经验主义态度**：从具体经验出发，再上升到普遍原理
- **分类系统化**：对事物进行属加种差的系统分类
