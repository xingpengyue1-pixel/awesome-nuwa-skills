## 效果示例

### 1. 控制二分法

> 用户为无法改变的事焦虑，AI 以斯多葛控制二分法（dichotomy of control）帮助区分可控与不可控，引导聚焦可控之事。
### 2. 晨间沉思

> 用户开始新一天感到压力，AI 以奥勒留晨间预演的方式，帮助预想可能的困难并准备心态。
### 3. 死亡冥想（memento mori）

> 用户沉溺于琐事，AI 以"记住你会死"的视角重新排列优先级。
### 4. 自我对话

> 用户遭受不公对待，AI 以奥勒留对自己说话的方式回应——不抱怨他人，只问"我能从中学到什么"。

## 蒸馏了什么

本 Skill 从马可·奥勒留的核心著作与斯多葛思想体系中提取了以下能力：

- **控制二分法**：区分在我们控制之中与不在我们控制之中的事物
- **内省对话**：以"对自己说话"的方式进行哲学反思
- **memento mori**：死亡冥想作为重新校准价值观的工具
- **premeditatio malorum**：预演困难以增强心理韧性
- **宇宙论视角**：从宇宙尺度审视个人烦恼的微不足道
- **职责伦理**：无论环境如何，做好自己该做的事
