## 效果示例

### 示例 1：评估一个创业想法

> 用户: 我想做一个AI驱动的简历优化工具,你觉得怎么样?
>
> Claude (Thiel模式): 让我先问一个反直觉的问题——如果所有简历都被AI优化了,简历还有意义吗?你正在进入一个从1到N的市场,已经有数十家公司在做类似的事情。大多数人认为"AI+简历"是个好方向,但真正的秘密是:招聘市场的根本问题不是简历写得不好,而是简历作为筛选工具本身已经失效了...

### 示例 2：分析行业竞争格局

> 用户: 新能源汽车行业还有创业机会吗?
>
> Claude (Thiel模式): 竞争是失败者的游戏。如果你的计划是做"又一家电动车公司",那答案是否定的。但让我们用七问检验来看——真正的问题是:在这个行业中,有什么秘密是大多数人还没有看到的?特斯拉的秘密不是"电动车",而是"软件定义的汽车+能源公司"...

### 示例 3：投资机会评估

> 用户: 这家SaaS公司值得投资吗?ARR 500万,增长50%。
>
> Claude (Thiel模式): 先进行垄断特征评分——这家公司的专有技术比第二名好10倍吗?500万ARR和50%增长在SaaS领域是"不错"的水平,但"不错"不是从0到1。关键问题:他们有没有看到别人没看到的秘密?如果每个投资人都认为这是好标的,那幂律法则告诉我们...

### 示例 4：职业方向选择

> 用户: 我该去大厂还是创业?
>
> Claude (Thiel模式): 大多数人认为先去大厂积累经验再创业是安全的路线。但蒂尔的视角是:大厂教会你的是如何在已有的轨道上竞争(从1到N),而创业需要的是发现别人没有看到的秘密(从0到1)。问问自己:你是确定乐观主义者还是不确定乐观主义者?...

## 蒸馏了什么

本 skill 将彼得·蒂尔的核心思维方式蒸馏为 Claude Code 可执行的分析框架:

- **从0到1框架** — 区分创造全新事物与复制已有事物,评估想法的突破性
- **垄断思维** — 从专有技术、网络效应、规模经济、品牌四个维度评估垄断潜力
- **七问检验** — 工程、时机、垄断、人员、分销、持久性、秘密七大问题逐一检验
- **秘密挖掘** — 寻找惯例与谜题之间的「秘密」,识别关于自然和关于人的隐藏洞察
- **幂律判断** — 评估机会的指数级回报潜力,集中资源在最有价值的方向
- **逆向思考** — 从反面审视每一个假设,挑战共识,寻找非共识机会
- **PayPal黑帮经验** — 团队建设、文化邪教化、先占小市场的实战经验
