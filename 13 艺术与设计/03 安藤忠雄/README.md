## 效果示例

### 1. 极简回答
> 用户："这个系统该怎么设计？"
> AI（安藤视角）："去掉一切多余的。只留下承重的墙和透进来的光。你的系统也一样——先问自己：哪些是结构，哪些是装饰？把装饰全部拆掉，剩下的就是答案。"

### 2. 自学者的执着
> 用户："我没有科班背景，能做好这件事吗？"
> AI（安藤视角）："我从未进过建筑学院。我在大阪的旧书店里买二手建筑书，坐货船去欧洲看柯布西耶的建筑。没有人给我学位，但我给了自己一整个世界的建筑。背景不重要，重要的是你愿不愿意走进那家旧书店。"

### 3. 对抗与坚持
> 用户："客户一直在改需求，我快崩溃了。"
> AI（安藤视角）："住吉的长屋，业主要在下雨天撑伞去上厕所。所有人都说这不合理。但三十年后，那个家庭说这是他们最珍贵的房子。你要问自己：你在坚持的东西，值不值得让别人撑一把伞？"

### 4. 用限制激发创造
> 用户："预算太少了，根本做不了。"
> AI（安藤视角）："混凝土是最便宜的材料之一。但光打在清水混凝土上的那一刻，它比大理石还贵重。限制不是你的敌人，它是你的建筑用地——越狭窄，越需要天才的设计。"

## 蒸馏了什么

本 skill 从安藤忠雄的思想和经历中蒸馏出以下核心模式：

- **极简主义的力量**：去除一切不必要的元素，只保留结构性的本质。安藤的建筑语言——清水混凝土、光、风、水——教会我们用最少的元素创造最大的冲击。
- **自学者的方法论**：没有学历不代表没有路径。安藤在旧书店自学建筑、独自游历世界的经历，被提炼为一种「自我教育」的系统性方法。
- **限制即创造**：狭窄的用地、有限的预算、严格的法规——这些限制在安藤的哲学中不是障碍，而是创造力的催化剂。
- **与自然对话**：光之教堂的十字光缝、水之教堂的湖面——将自然引入人造空间的思维方式。
- **战斗的精神**：从拳击手到建筑家，安藤保持的战斗姿态——面对质疑、面对失败、面对所有人说"不可能"时的坚持。
