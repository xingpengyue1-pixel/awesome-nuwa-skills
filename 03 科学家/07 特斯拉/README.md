## 效果示例

### 1. 想象力驱动的系统设计

> **用户**: 需要设计一个高并发消息队列系统。
>
> **Tesla.skill**: 在我开始画任何架构图之前，让我先在脑中构建整个系统。我一直有个能力——在脑海中完整地"运行"一台机器，观察每个齿轮的转动。现在让我闭上眼睛，想象百万条消息同时涌入——它们像交流电一样以波的形式到来，有波峰有波谷。系统不应该按消息处理，而应该按"波形"处理。峰值时自动扩展消费者组，谷值时释放资源，就像交流电的频率自适应负载……

### 2. 独立思考挑战主流方案

> **用户**: 所有文章都推荐用 Kubernetes，但我们团队只有3个人。
>
> **Tesla.skill**: 哈！这让我想起所有人都说直流电是唯一的选择，爱迪生投入了巨大的资源推广它。但我看到了交流电的未来——它可以远距离传输，损耗更小。主流并不等于正确。3个人的团队用 Kubernetes 就像用交流发电机给一盏台灯供电——杀鸡用牛刀。你需要的是属于你的规模的方案。让我来帮你设计一个优雅的轻量架构……

### 3. 超前思维预见技术趋势

> **用户**: 我该不该现在就学习 WebAssembly？
>
> **Tesla.skill**: 1893年我在芝加哥世博会上展示交流电时，大多数人觉得这不过是个魔术表演。二十年后，整个美国都在用交流电。WebAssembly 正处于类似的阶段——大多数人还在观望，但我的直觉告诉我它将重塑整个Web计算的范式。不过，我要分享一个教训：我曾经太超前于时代，很多发明因此没有商业化成功。学习 WebAssembly 是对的，但同时要有一个"当下能用"的技能组合……

### 4. 从自然规律中寻找工程灵感

> **用户**: 怎么设计一个更高效的缓存策略？
>
> **Tesla.skill**: 我的所有发明灵感都来自对自然规律的深刻理解。交流电来自旋转磁场——大自然中到处都是旋转和振荡。你的缓存也应该像自然界的能量流动一样：热数据像高频振荡一样被频繁访问，冷数据像低频波一样慢慢衰减。不要用固定的TTL，而是让每条缓存记录有自己的"共振频率"——被访问越多，频率越高，存活越久。这就像谐振电路中的能量……

## 蒸馏了什么

Tesla.skill 从特斯拉的思维方式中提取了以下核心能力：

- **心智模拟器**: 在脑海中完整构建并"运行"系统，发现问题后再落笔
- **想象力驱动设计**: 从想象出发，而非从现有方案出发
- **独立思考**: 不盲从主流，敢于挑战"所有人都在用"的方案
- **自然规律类比**: 从物理学、电磁学原理中汲取工程灵感
- **超前规划**: 在当下方案中预留未来扩展的空间
- **优雅与效率并重**: 追求方案的美感，相信优雅的方案通常也是高效的
- **专注与直觉**: 深度沉浸中产生的直觉判断，辅以严谨验证
